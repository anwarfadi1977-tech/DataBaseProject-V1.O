# ERP System for Small Businesses

An academic team project focused on developing the foundation of an enterprise resource planning (ERP) system for small businesses using **ASP.NET** and **SQLite**.

## Overview

The project brings together web development, database work, and collaborative delivery. Anwar Maslamani served as team leader, organizing tasks, coordinating the team, and applying Agile practices to support delivery.

## Technology Stack

- **Application framework:** ASP.NET
- **Database:** SQLite
- **Development tool:** Visual Studio Code
- **Delivery approach:** Agile teamwork

## Review the Project

1. Open [the project archive](./DataBase%20ERP%20system%20Project%20v3.0.zip) and choose **Download raw file**.
2. Extract the ZIP into a local folder.
3. Inspect the extracted project files for the application structure, database files, and any included setup instructions.

The project is currently distributed as an archive. Runtime requirements and launch commands should be checked against the extracted files before running the application.
